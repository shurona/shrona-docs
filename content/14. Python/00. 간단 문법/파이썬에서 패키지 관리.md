# Python `__init__.py` 란

## 한 줄 요약
- 디렉토리를 Python **패키지**로 선언하는 파일._
## 왜 필요한가?
- Python은 `__init__.py`가 있는 디렉토리만 패키지로 인식한다.
- 빈 파일이여도 상관 없다.
- 아래가 패키지 디렉토리 구조 예시이다. 
```txt
app/
├── init.py       ← 없으면 app을 패키지로 못 인식
├── services/
│   ├── init.py
│   └── parser.py
```
- import 가능 예시
```python
# __init__.py가 있어야 이런 import가 가능
from app.services.parser import load_all_documents
```
