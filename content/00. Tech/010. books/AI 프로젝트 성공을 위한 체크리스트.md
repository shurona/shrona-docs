# 생성 LLM이 적합한 문제
- 자연어 처리 작업(텍스트 분석, 추철, 분류)
- 분석 업무나 문헌 자료를 정리하고 요약하는 작업
- 검증이 쉬운 문제를 해결하는 것
	- 객관적 판단 기준
	- 즉각적인 피드백
	- 역할 분담
# 나를 다르게 만들기
- 라스트 스마일 문제
	- 이건 뭐지

## 중요 결정 방법론
- 전문가의 의사결정 과정을 체계적으로 분석하는 기법
- 전문가와 초보자 사이의 차이점을 명확히 이해 후 개선 방안과 도메인 지식과 숨겨진 업무 노하우를 도출
- 전문가가 **어떻게** 판단하고 결정하는 지 
	- 특별한 사건 찾기 -> 시간 순서표 만들기 -> 깊이 파고 들기 -> 가정 해보는 질문하기 -> 숨겨진 정보 및 노하우 찾기
### 분석할 중요 사건 선정
- 비일상적인 사건
- 도전적인 사건
- 내공이나 숨겨진 전문성이 드러나는 사건
### 시간 순서표 만들기
- 사건에서 일어난 일들은 시간 순서대로 정리한다
	- 모든 일을 다 기록하지는 않는다.
- **핵심 결정이 내려진 순간**이나 **상황이 크게 바뀐** 지점
### 깊이 파고 들기
- 전 단계에서 내용을 자세히 분석하는 시간
- 전문가에게 질문을 잘 한다.(전문가가 의식하지 못한 노하우를 찾으면 Best)
### 가정해보는 질문 하기
- 말로 설명하기 어려운 노하우를 찾아야 한다.
- 질문 예시
	- 이 결정을 내릴 때 고려한 중요 요소
	- 다른 선택지는 뭐가 있었나요?
	- 판단을 내릴 때 도움이 된 가장 정보
	- 다음 번에는 더 나은 결정을 내리는 데 도움이 되는 피드백을 얻고 연습할 수 있을까요
### 핵심
- 위에서 정리한 노하우를 인공지능이 이해하고 자동화 할 수 있게 한다.

# AI 프로젝트의 주의 사항
## 가드레일 설치
- 전처리 가드레일
	- LLM의 입력에 악의적 및 도메인 경계를 벗어난 것에 대해서 가드레일을 설치해야한다.
- 생섲 중 보호 가드레일
		- LLM 시스템 보호 및 에이전트의 역할 격리를 유지
- 후처리 가드레일
	- 출력에 대한 중요한 데이터가 나가지 않도록 가드레일을 설치해야한다.
## 게이트웨이
- 토큰에 대한 비용 제한을 둘 수 있다. 
### 나머지
- 프롬프트 템플릿을 정해서정확한 답을 관리할 수 있다. 
- 시멘틱 캐시를 사용할 수 있다. 
	- 벡터 디비를 통해서 임계치가 넘는 유사도가 들어오면 같은 값을 반환한다. 
- 이전의 출력을 입력으로 넣어준다.
  기존에 했던 대화가 컨텍스트로 들어가야한다.(단기 메모리, 장기 메모리)

# 벡터 디비
## 데이터 표현 법
- 희소 백터
	- 주요 키워드만 뽑아서 변환하면 벡터가 표현할 수 있는 차원 중
	  일부만 사용하게 되고 나머지 많은 차원은 0으로 비어 있게 된다.
	- 특정 키워드에 맞는 단어 검색
- 밀집 벡터
	- 글 전체를 임베딩 벡터로 변환하면 거의 모든 차원을 사용한다.
	- 콘텐츠 전체의 의미를 검색하는 데 적합한 구조
- 벡터 검색 + 키워드 검색 => 결과 통합 => 재순위자(Reranker)
