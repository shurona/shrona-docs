# Consistent Hashing
해시 링을 사용해서 노드와 데이터를 같은 해시 공간에 매핑하는 방식으로 동작한다.
## 해시 공간을 원형으로 구성
해시 함수를 사용해서 특정 범위를 가진 해시 링(Hash Ring) 형태로  만든다.    
각 서버를 해시 함수로 변환하여 해시 링의 특정 위치에 배치한다.

```

|-------- Server A ------- Server B ------- Server C ------|
```

## 데이터의 해시 값을 링에 매핑
각 데이터도 동일한 해시 함수로 링에 매핑이 된다.   
저장된 키를 서버에 매핑을 하기 위해서는 시계 방향으로 가장 가까운 노드에 저장이 된다.
## 서버 추가 및 제거 시 데이터 이동
### 서버 추가 시
기존의 서버가 아래와 같이 해시링위에 있다고 가정을 한다.
이후 서버 D가 추가 될 경우
```
|---- A (서버 1) ---- B (서버 2) ---- C (서버 3) ----|

==>

|---- A (서버 1) ---- B (서버 2) ---- D (서버 4) ---- C (서버 3) ----|
```
D 서버의 위치 부터 B 서버의 위치에 속한 데이터들을 기존에 C 서버에서 처리를 진행하였으나 해당 위치의 데이터들만 D 서버로 이동하면 된다.
### 서버 삭제 시
기존의 서버가 아래와 같이 해시링위에 있다고 가정을 한다.
이후 서버 D가 삭제 될 경우
```
|---- A (서버 1) ---- B (서버 2) ---- D (서버 4) ---- C (서버 3) ----|

==>

|---- A (서버 1) ---- B (서버 2) ---- C (서버 3) ----|
```
D 서버가 관리하고 있던 데이터들을 시계방향으로 가장 가까운 C서버로 이전을 시켜주면 된다.

### 결론
서버가 추가 및 삭제 될 때 마다 관련된 서버의 데이터만 옮기면 되고 다른 연관 되지 않은 서버의 데이터는 옮길 필요가 없다.   
위의 예시에서 살펴보면 관련이 있는 C, D 서버만 데이터가 변동이 있을 뿐 A와 B에는 영향을 주지 않는다.
