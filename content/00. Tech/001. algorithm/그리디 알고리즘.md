# 개념
- 현재 상황에서 가장 좋아보이는 선택을 단계마다 수행한다.
- 전체적인 결과를 고려하지 않고 각 단계에서 최적의 선택을 선택한다.
	- 한 번 선택한 결정을 번복하지 않는다.
# 초반에 접근 하지 못한 문제들
## 스위치 문제
[문제 링크](https://www.acmicpc.net/problem/2138)
해당 문제는 기존의 스위치를 변경해서 목표인 스위치 형태로 변화시키는 문제이다.   
한 칸을 변화 시키면 양쪽의 칸이 같이 변환이 되므로 처음에는 dfs와 같은 형태로 접근을 해야 하는지 고민을 하였다. 하지만 들어올 수 있는 최대 길이 100,000개 이므로 시간 제한에 걸릴 수 있다는 것을 확인하였다.   
이후 왼쪽에서 부터 하나씩 맞춰간다는 느낌으로 접근을 하고자 하였고 따라서 아래의 이유로 그리디를 적용하였다.
- 왼쪽에서 부터 이미 맞춰서 변화을 진행하였으면 이미 맞은 상태에서는 변환할 필요가 없다.
- 지역적으로 독립적으로 최적의 선택을 내릴 수 있다.
### 접근 방법
- 첫 번째 칸은 무조건 변환한다고 가정한다. 
- 두 번째 칸 부터는 하나 왼쪽 칸이 변화할 필요가 있냐에 따라서 스위치 변환을 정한다.   
  이유는 이미지 지나간 칸에 대해서는 더 이상 접근하지 않기 때문이다.
- 이러한 방식으로 끝까지 진행한다.
